# OpenRVL

Headers for the Revolution (RVL) SDK, forked from [open_rvl](https://github.com/Sammi-Husky/open_rvl).

This copy is maintained as part of the [Brawl decompilation](https://github.com/doldecomp/brawl) and is the source of truth for these headers. It is no longer synced with open_rvl, so changes should be made here rather than upstream.

`src/` contains open_rvl's original SDK decompilation, which targets the SDK version used by Wii Sports rather than Brawl's. It is kept for reference and is not built by this project.
